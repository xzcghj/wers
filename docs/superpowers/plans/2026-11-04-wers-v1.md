# WERS v1 Implementation Plan

> **For agentic workers:** executed natively in this session (user waived review gates and asked not to be asked).

**Goal:** A VST3 plugin for Windows x64 that scores and fixes vocal intelligibility word by word.

**Architecture:** `wers_core` is pure C++20 without JUCE (DSP, analysis, link), tested with doctest under sanitizers.
`src/plugin` and `src/ui` are a thin JUCE layer. `whisper.cpp` sits behind one interface so everything works without it.

**Tech Stack:** C++20, JUCE 8.0.17-security, whisper.cpp v1.9.5, doctest v2.5.3, CMake, MSVC 14.44 / GCC 13, pluginval 1.0.4.

**Spec:** `docs/superpowers/specs/2026-11-04-wers-design.md`

## Global Constraints

- VST3 on Windows x64 is the deliverable; Linux builds exist only for testing.
- No allocations, locks or I/O on the audio thread.
- Zero parameters mean output = input delayed by the reported latency.
- User-visible text is Polish; code, tests and comments are English.
- Score thresholds: below 50 dies, below 65 fades; fix target 78.
- Static MSVC runtime; whisper code runs only after an AVX2 check.

## Review Focus

- Host passes a block larger than prepared, or changes rate between prepares: no crash, correct audio.
- No playhead, stopped transport, loops and jumps: fixes never fire at a wrong time, capture stays consistent.
- Project closed during analysis: destructor returns promptly, no crash.
- Vocal edited after analysis: fixes turn themselves off.
- Corrupt, empty or older saved state: plugin loads with defaults and keeps working.

### Task 1: Build skeleton and DSP primitives
Files: `CMakeLists.txt`, `src/core/dsp/Filters.h`, `Oversampler.h`, `tests/test_filters.cpp`.
Produces: `Svf`, `Biquad`, `BellBank`, `Halfband2x`, `DelayLine`, `ScopedFlushDenormals`.
Tests: bell gain at centre equals G within 0.05 dB; unity gain is exact; oversampler latency equals the reported value.

### Task 2: Loudness, devices, monitor
Files: `src/core/dsp/Loudness.*`, `DeviceProfiles.*`, `Monitor.*`.
Tests: 997 Hz sine at -20 dBFS stereo reads -20.0 LUFS +-0.1; true peak catches inter-sample overs; Spotify gain rules
reproduce the -20 LUFS / -5 dBTP -> -16 LUFS example; offline rendering bypasses the simulation.

### Task 3: Phoneme classifier and Fonem
Files: `PhonemeClassifier.*`, `Fonem.*`.
Tests: synthetic vowel, sibilant, burst and breath are classified correctly; sibilant noise gets no added distortion while
a vowel does; null test at zero; block-size independence; bypass latency.

### Task 4: Miejsce
Files: `Place.*`. Tests: sub below 150 Hz and side signal unchanged within 0.1 dB; band cut follows a vocal; plan cut
fires ahead of the sound; depth 0 is a null.

### Task 5: Przestrzen
Files: `Space.*`. Tests: amount 0 is a null; wet level under active vocal at least 8 dB lower than in the gap; stable at
extreme settings; no NaN.

### Task 6: Capture and link
Files: `TimelineStore.*`, `LinkHub.*`, `Plan.h`. Tests: jumps and loops land at right indices; concurrent arm/stop under
TSan; plan swap is safe; hub survives instance destruction order.

### Task 7: Scoring, segmentation, fix planner
Files: `Sii.*`, `Segmenter.*`, `FixPlanner.*`, `tools/wers_cli.cpp`.
Tests: reference SII values from the published algorithm; score rises with SNR; same input gives identical output; planner
reaches the target or stops at limits; end to end on real stems: predicted score vs score of the rendered audio within 8 points.

### Task 8: Text recognition
Files: `Recognizer.*`, `LyricAligner.*`. Tests: alignment corrects spelling and keeps times; missing model degrades to
fragments; abort returns fast; real Polish vocal transcription checked when a model file exists.

### Task 9: Fix engine and stale detection
Files: `VocalFixEngine.*`, `Fingerprint.*`. Tests: fix fires at the right sample with latency accounted for; replaced vocal
disables fixes within 2 s; loop and jump behave.

### Task 10: JUCE processor
Files: `src/plugin/*`. Tests: allocation counter around processBlock; state round trip; corrupt state; oversized block;
pluginval strictness 10 on Linux.

### Task 11: Interface
Files: `src/ui/*`. Tests: editor renders under Xvfb in all roles and states, snapshots reviewed against the mockup;
open/close stress.

### Task 12: Windows build and real host
Files: `scripts/build_windows.bat`. Run on the user's computer: unit tests, pluginval strictness 10, REAPER load.

### Task 13: Independent review and final report
Fresh-eyes review of the whole tree, fixes, then a report of what was and was not tested.
